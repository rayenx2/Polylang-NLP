What this project does

Polylang-NLP is a language intelligence platform for companies that handle customer feedback, reviews, and documents across multiple languages. It does two things:

  • Multilingual Sentiment Analysis: understands whether a review is positive, negative, or mixed in English, German, French, Spanish, or Chinese, and can break sentiment down per topic ("aspect") like price, service, or battery life.
  • Retrieval-Augmented Question Answering: lets you build a knowledge base of documents, then ask natural-language questions. The system searches the knowledge base semantically (FAISS + sentence embeddings) and extracts the exact answer from the most relevant document.

This is a static demo, all results below were pre-computed by running the real models locally and saving the outputs. No backend is required to view this page.
